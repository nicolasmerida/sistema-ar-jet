# Backend — Sistema AR-Jet

API y lógica de negocio del sistema, desarrollada en **Node.js con TypeScript y JavaScript**.

## Base de datos

PostgreSQL alojado en **[Neon](https://neon.tech/)**.

1. Copiar `.env.example` como `.env`.
2. Completar `DATABASE_URL` con el connection string del proyecto en Neon (se consigue en el dashboard de Neon → *Connect*).
3. **No subir nunca el `.env` al repo** (ya está ignorado en el `.gitignore`).

Completar con instrucciones de instalación y ejecución cuando se inicialice el proyecto.
